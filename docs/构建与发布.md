### 1.1 已知问题：CET 导致的编译失败

未打全补丁的 Windows 10 上，`dotnet build` 会报：

```
error : Fatal error.
error : Your Windows doesn't fully support CET. Please install all available Windows updates.
```

根因：SDK 自带 `csc.exe` / `VBCSCompiler.exe` 的 PE 调试目录里带
`IMAGE_DEBUG_TYPE_EX_DLLCHARACTERISTICS`（值 `0x1` = CET_COMPAT），当前 `coreclr` 见到该标记直接退出，
**没有** 环境变量或 MSBuild 属性可以关掉它（`<CETCompat>false</CETCompat>` 只影响我方产物）。

本机使用的临时处理方式如下。`.toolchain/` 只用于当前开发机，已通过 `.gitignore` 排除，**不会提交到公开仓库**：

1. `.toolchain/roslyn/`：SDK Roslyn 的副本，`csc.exe` 与 `VBCSCompiler.exe` 那两个字节已清零；
2. `build/patch-cet.py`：可复用的 PE 补丁脚本（换机器/换 SDK 后重跑）；
3. `Directory.Build.props`：检测到 `.toolchain/roslyn/csc.exe` 存在时，自动设置
   `CscToolPath` / `CscToolExe=csc.exe` / `UseSharedCompilation=false`；
4. 全仓 `CETCompat=false`，保证我方 apphost 也不带该标记。

系统打全补丁后不需要 `.toolchain/`，构建会自动回到 SDK 自带编译器。需要在本机复现时：

```powershell
$sdk = (dotnet --list-sdks | Select-Object -Last 1).Split(' ')[0]
New-Item -ItemType Directory -Force .toolchain | Out-Null
Copy-Item -Recurse "$env:ProgramFiles\dotnet\sdk\$sdk\Roslyn\bincore" .toolchain\roslyn
python build\patch-cet.py .toolchain\roslyn\csc.exe .toolchain\roslyn\VBCSCompiler.exe
```

## 2. 命令

```powershell
# 开发构建
dotnet build src/WinTool.App/WinTool.App.csproj -c Debug

# 单测（34 项，纯 Core，不弹窗）
dotnet run --project tests/WinTool.Core.Tests

# 发布：自包含单文件（默认）
powershell -NoProfile -ExecutionPolicy Bypass -File build\publish.ps1

# 发布：框架依赖版（体积小，目标机需装 .NET 10 桌面运行时）
powershell -NoProfile -ExecutionPolicy Bypass -File build\publish.ps1 -FrameworkDependent

# 其它架构 / 保留旧产物
powershell -NoProfile -ExecutionPolicy Bypass -File build\publish.ps1 -Runtime win-arm64 -NoClean
```

发布参数（脚本内固定，改动需同步本节）：`PublishSingleFile=true`、
`IncludeNativeLibrariesForSelfExtract=true`（WPF 有原生 DLL）、`EnableCompressionInSingleFile=true`、
`DebugType=none`、`--self-contained true`。

## 3.1 验收脚本（发布后必须跑）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build\smoke.ps1 -Exe dist\WinTool-win-x64\WinTool.exe
```

它用 UI 自动化真的点一遍，然后校验落盘文件，共 20 项断言：

| 组 | 断言 |
|---|---|
| 待办 | 两条入列 → 勾选第一条 → 清理后 `todos.json` 只剩未完成那条且 `order=0`；留底 `.md` 出现 `## yyyy-MM-dd HH:mm`、`- [x] smoke todo A`、`id: <32 hex>` |
| 账号密码 | `vault.json` 含该标题、密码为明文（D1a 预期行为）、ACL 不含 `Users`/`Everyone` |
| 随笔 | `notes.json` 含正文，且不含 `\r\n`（换行已归一） |
| 悬浮球 | 点「隐藏到悬浮球」后主窗口句柄为 0，且存在宽度 < 120 的顶层窗口 |

被测目录里会留下测试数据，**跑完请把 `data\` 与 `待办留底\` 删掉**再交付；本仓库的
`dist\WinTool-win-x64\` 已清理干净。脚本退出码 0 = 全通过。

## 4. 首次运行行为

1. 解析路径：数据根 = `exe 同级\data`；留底目录 = `exe 同级\待办留底`。
2. 两者都做**写探针**（建临时文件再删）；不可写时分别回退到 `%LOCALAPPDATA%\WinTool\data` 与数据根下的 `待办留底`。
3. 创建上述目录，读入 `todos.json` / `vault.json` / `notes.json` / `settings.json`（缺失即视为空，不建默认样例数据）。
4. `vault.json` 首次写出时收紧 ACL（当前用户 + SYSTEM，断开继承）；失败只提示不阻断。
5. 弹一次托盘气泡告知「数据根 / 留底目录 / 唤出方式」，写回 `settings.json` 的 `welcomeShown`。
   —— 这里刻意不用模态 MessageBox：用户可能在跑全屏程序，模态框会抢焦点且容易被误点掉。

## 5. 运行时数据文件

| 文件 | 内容 | 备注 |
|---|---|---|
| `data\todos.json` | 待办（`id/text/done/createdAt/completedAt/archivedAt/order`） | 清理后已完成项从这里消失 |
| `data\vault.json` | 账号密码，明文 JSON | 记事本可读可改；ACL 只留当前用户与 SYSTEM |
| `data\notes.json` | 随笔（`id/title/content/createdAt/updatedAt`） | 正文换行统一为 `\n` |
| `data\settings.json` | `archiveDirectory`、`welcomeShown` | 留底目录为空表示用默认 |
| `待办留底\待办留底-YYYY-MM.md` | 清理留底，按月一个文件 | 月内追加，旧月写出即冻结 |

所有写盘都走 `AtomicFile`：临时文件 + `Flush(flushToDisk:true)` + `File.Move(overwrite:true)`，
失败重试 5 次 × 100 ms。

## 6. 交互约定（打包后仍需人工确认的点）

- 窗口右上角 `×` / `Alt+F4` = **隐藏到悬浮球**，不退出进程。
- 退出只有一条路径：托盘图标右键 → 退出。
- 唤醒：点悬浮球（52×52，贴屏幕左右竖边）或按 `Ctrl+Alt+W`。
- 单实例：重复启动只把已有实例唤出（Mutex + 命名管道）。

## 7. 未做的事（等产品决策，不要在发布脚本里偷偷补上）

- **安装包**（MSI/NSIS）、开机自启、卸载保留策略 —— 全部属于 D7，未定。
- 数据根是否可改 —— D7；目前固定为 exe 同级，可写性回退是唯一的分支。
- 球尺寸/贴边距/热键 —— D3a/D3b/D3e，占位值集中在 `src/WinTool.App/Infrastructure/Provisional.cs`。

## 8. 常见排错

| 现象 | 处理 |
|---|---|
| `MSB3027/MSB3021 文件被 WinTool 锁定` | 先 `powershell -NoProfile -Command "Get-Process WinTool \| Stop-Process -Force"` |
| 启动后无窗口、只有托盘图标 | 正常：上次可能停在隐藏态；点托盘图标或按热键唤出 |
| 热键无反应 | 设置页会显示「未生效」；多为 `Ctrl+Alt+W` 被其它程序占用（`RegisterHotKey` 返回 1409） |
| 清理已完成报「留底目录不可写」 | 用设置页改留底目录；程序不会静默换目录后删条目 |
| 双击 exe 无任何反应 | 已有实例在跑（单实例）；看托盘 |
